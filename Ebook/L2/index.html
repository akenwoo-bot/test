⚡ 餐廳冷知識

🚄 外送員快到嚇人：網路送資料的速度接近「光速」，一秒可以跑 30 萬公里！所以就算廚房在地球另一端，你還是覺得「幾乎瞬間」就吃到菜了。
🍲 每次都是現做：伺服器每次都會「重新做一道新菜」，所以你按「重新整理」時，它會再做一次！這就是為什麼新聞、比分、留言會一直變新。
🧊 冰箱超大：資料庫就像一台超級冰箱，裡面放著幾百萬張照片、影片和文字。廚師做菜前，都要先開冰箱拿「食材」！

🎮 小測驗：你打開網頁時，外送員「第一次」帶去廚房的是什麼？

⚡ 實驗室冷知識

📜 全世界第一張網頁：1991 年发明的第一張網頁，其實只有黑白文字，沒有圖片、沒有顏色、不能動！因為當時還沒有 CSS 和 JavaScript，只有 HTML 骨頭。
🎨 CSS 的名字：CSS 的全名是「層疊樣式表」，「層疊」的意思是：像疊衣服一樣，後寫的規則會蓋掉先寫的規則！所以工程師常常要研究「誰蓋掉了誰」。
🧠 程式會「思考」：實驗 C 裡的「如果…就…」叫做「條件判斷」，是程式最厲害的地方——你的遊戲、App、甚至紅綠燈，背後都充滿了這種判斷！
